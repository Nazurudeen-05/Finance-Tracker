    About

    Finance Tracker is a personal finance application with a Java REST API and a web interface. It records income and expenses, summarizes spending by category and shows monthly totals.

    Technology

    • Java 17+, Spring Boot 3, Spring Data JPA, H2 database
    • JUnit 5 and Mockito tests, GitHub Actions CI
    • Plain HTML, CSS and JavaScript front end, no build step

    API

    • GET /api/transactions list transactions
    • POST /api/transactions add a transaction
    • DELETE /api/transactions/{id} delete one
    • GET /api/transactions/summary totals and spending by category

    Roadmap

    • CSV import with duplicate detection
    • Rule-based auto-categorization
    • Budgets with overspending alerts
    • Server-side authentication with Spring Security
    • Docker image and OpenAPI documentation
