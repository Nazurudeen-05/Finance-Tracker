    About

    Finance Tracker is a personal finance app with a Java REST API and a web interface for recording income and expenses, spending by category and monthly totals.

    Live today

    • Transactions API: GET/POST /api/transactions, DELETE /api/transactions/{id}
    • Dashboard, transactions table, reports

    Preview in this interface

    • Accounts, spending limits and bills are saved in your browser while their APIs are being built. Limit usage and the forecast are calculated from your real transactions.

    Not built yet

    • Split expenses, receipt upload, real authentication, CSV import
